## 📖 Sobre o repositório

Este repositório foi criado para **centralizar e organizar o conteúdo acadêmico** do curso de Análise e Desenvolvimento de Sistemas, facilitando o acesso aos arquivos de cada semestre e o acompanhamento da evolução dos estudos.

A estrutura está dividida por períodos, permitindo localizar rapidamente o material correspondente a cada etapa do curso.

## 🚀 Como acessar

Você pode explorar os materiais diretamente pelo GitHub, clicando nos links da tabela acima.

Para obter uma cópia do repositório no computador, execute:

```bash
git clone https://github.com/BernardoCipolli/ADS-SEMESTRES.git
```

Em seguida, acesse a pasta criada:

```bash
cd ADS-SEMESTRES
```

Abra o diretório do semestre desejado para consultar seus arquivos.

## 🎯 Objetivos

- Organizar os conteúdos por semestre.
- Facilitar a revisão e a consulta dos materiais acadêmicos.
- Manter um histórico de aprendizado durante a graduação.
- Compartilhar os estudos e a evolução ao longo do curso.
